# 终末地主题中期设计闸门

本目录中的稿件不参与 `npm run build`，也不部署到 SillyTavern。它们用于在继续修改
JSON 前，先验证构图、材质、排版和信息层级。

## 唯一参考系

- 主样本：`research/reference/official-longform/2025-12-09-dijiang-update-01.png` 至
  `04.png`。
- 结构数据：`references/UI_FACTS.md` 的「官号长图实测」。
- 当前真实内容：运行时首页前三条最近聊天、欢迎消息与原生功能入口。
- 排除：角色实机、剧情对话框、大版本封面、深色 `[END]` 尾页和无证据英文微文案。

## 页面工作

把 SillyTavern 首页整理成一张可操作的档案索引页。用户应先读到分区标题和最近聊天，
再进入欢迎消息；装饰不能抢过名称、日期和操作。

## 一对一映射

| 官方构件 | ST 真实内容 | 中期稿处理 |
| --- | --- | --- |
| 两层章节头 | 最近聊天标题 | 真实顺序编号 `01`；白底标题；右侧黄条 |
| 白纸正文 | 最近聊天列表 | 白纸微网格；只保留名称、日期、大小和操作 |
| 中灰过渡 | 最近聊天与欢迎消息边界 | 结构网格贯穿，斜纹仅局部 |
| 正文标题 | 欢迎助手消息 | 小黄状态标，不使用整块黄色姓名牌 |
| 功能入口 | API／角色／扩展按钮 | 无框文本工具列，保留真实名称 |

## 主动删除

- 最近聊天的原始消息预览；它会暴露 `<dream_plot>` 等宿主内容，且 CSS 无法语义清洗。
- 常驻按钮方框和每行三枚独立小卡片。
- 灰底上的全铺斜纹。
- 普通助手消息的黄色姓名胶囊。
- 无官方依据的英文微缩文案。

## 验收闸门

1. 80% 以上可见内容是安静白纸，不是科技纹理墙。
2. 一个视口只有章节头承担强黄色签名。
3. 标题／正文接近官方 `1.77×`，正文行高 `1.6`。
4. 所有文字都来自真实界面或官方固定标签。
5. 桌面与 390px 均不靠隐藏关键操作换取整洁。
6. 用户确认概念稿后，才把对应规则逐项搬回 JSON。
