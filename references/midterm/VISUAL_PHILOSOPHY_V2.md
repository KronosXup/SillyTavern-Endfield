# 校准留白

空间不是等待填满的空缺，而是秩序本身。大面积安静的浅色平面承担阅读与呼吸，结构只在内容发生转折时显形；窄轨、短线、编号和边界从不争夺中心，它们像校准仪器留下的读数，精确、克制，并且彼此保持足够距离。

层次不依赖悬浮阴影，而由材料的微妙切换建立：洁净纸面、略冷的工作灰、少量炭黑证据块以及一束高纯度信号色。纹理必须近看才被察觉，小网格与定位十字属于纸张的生产痕迹，局部排线属于结构接缝；任何纹理都不能成为主角，更不能均匀铺满画面。

节奏来自密度而非装饰。长段内容保持连续、宽松和清楚，章节转折处才压缩行距、强化横向边界或短暂提高色彩浓度。强色一次只承担一个决定性的动作，其余区域以细微灰阶和准确留白维持张力，让视线自然完成“进入、阅读、停顿、继续”的循环。

构图强调机械精度中的少量不对称。主轴稳定，辅助标记可以偏移；大块面保持完整，小标记则像经过测量后钉入纸面的坐标。字体不是风格表演，而是信息结构的一部分：标题坚实、正文平静、数字狭长，任何字重和字号变化都必须有明确职责。

最终画面应像经过无数次微调的工业出版物：边界、间距、灰阶和信号色都经过耐心校准。精致感来自删减后的准确，而不是添加后的复杂；每一处可见痕迹都必须证明自己对秩序有用，否则就应消失。
