# 武陵 UI 动效事实表

更新时间：2026-08-21

当前还没有足以支撑“复刻游戏动效时序”的录屏与逐帧证据，因此本文件先记录验证门槛，
不把主观感觉写成事实。

## 已确认

- 静态资源中反复出现成束细流线、分叉和导向性折线；它们适合形成状态变化的运动方向。
- SillyTavern 本身支持 `reduced_motion`，主题 CSS 也必须尊重
  `prefers-reduced-motion: reduce`。

## alpha.1 暂定交互假设

- 消息悬停或键盘聚焦时，左侧细流线由短段延展为整段。
- 输入区聚焦只改变轮廓、顶线和发送按钮色，不做持续循环动画。
- 时长只作为宿主可用性试验值，不宣称来自游戏：反馈 `120ms`，延展 `180ms`。

## 下一轮取证问题

1. 武陵菜单进入、页签切换、列表刷新分别沿哪个方向发生？
2. 线束是连续流动、分段点亮，还是只承担静态引导？
3. 遮罩、面板和文字是否同速出现？是否有可测的先后关系？
4. 息壤相关界面的动效是否与普通武陵面板存在独立节奏？
5. 低性能或减少动态效果模式下，游戏如何降级？
