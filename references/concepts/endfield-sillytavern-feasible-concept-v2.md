# 终末地 SillyTavern 可实现概念图 v2

- 图像：`endfield-sillytavern-feasible-concept-v2.png`
- 底图：当前运行中的普通 SillyTavern 1.18.0，1280 × 720。
- 用途：JSON-only 视觉方向评审；用户确认前不据此改主题。
- 方向：终末地整体风格，不限定武陵。

## 实现边界

概念图保持了现有顶栏、最近聊天浮层、聊天列、消息、快捷按钮、输入区和发送按钮。
没有新增左右侧栏、频道、状态面板或附件面板。

| 概念表现 | 单 JSON 实现路径 | 可行性 |
| --- | --- | --- |
| 黑色侧边留白与弱网格 | `body` 背景色与多重线性渐变 | 可实现 |
| 白灰聊天与浮层 | 现有容器背景、边框、阴影 | 可实现 |
| 顶栏图标分格和黄色激活态 | 现有按钮选择器、伪元素、状态类 | 可实现，需逐项核对状态类 |
| 消息细轨与索引标记 | `.mes::before`／`.mes::after` | 可实现 |
| 小切角 | `clip-path` 或伪元素遮角 | 可实现 |
| 黄色发送按钮 | `#send_but` 背景、边框与图标色 | 可实现 |
| 浮层开合和按钮反馈 | CSS transition | 可实现 |
| 游戏原字体完全一致 | 需要字体文件与许可 | 当前不承诺 |
| 多组件严格错峰转场 | 需要事件与时序控制 | JSON-only 不承诺；触发时再评估薄插件 |

## 明确排除

- 不把概念图扩展成新的应用信息架构。
- 不通过主题 CSS 改变现有控件含义、顺序或点击区域。
- 不再使用暗青作为主题主色，也不把武陵限定为整套主题身份。
