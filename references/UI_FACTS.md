## 实机视频校正

武陵建造实机逐帧记录见 `references/VIDEO_FACTS.md`。它否定了“从
`deco_guide_wuling_titlebg` 推出武陵整套 UI 以暗青为主”的早期解释。

- 蓝图仓库是大面积白灰底、黑字，卡片以蓝／黄编码，主操作按钮为黄色。
- 待放置蓝图是半透明蓝色，建造范围使用黄黑警戒线。
- 正常运行时传送带呈橙黄、液体管线呈蓝色；二者是系统内容／状态色，不是地区主色。
- 技术树是白底、黑标签、黄色激活路径，局部浅薄荷绿只承担分区或选中层。
- 放置失败直接叠加红色边框和管线，证明颜色首先服务交互语义。

## 当前设计解释

- 终末地通用骨架采用白／黑灰；黄色承担主要交互与激活状态。
- 蓝色只用于蓝图、流体、连通或预览语义，不把聊天界面整体染蓝。
- 武陵提取资源中的青绿／薄荷只作为地区层、息壤层和低强度导流细节。
- 深暗青只可作为少量容器候选，不能再称为武陵主色。
- 保持聊天正文高可读，装饰降低对比度；不把半圆阵列铺成抢眼背景。

## alpha.1 结论

现有 `alpha.1` 的“暗青主视觉”设计前提已被实机证据否定。它只保留为工程链路样本，
不得继续扩展，也不得作为下一版视觉基线。

## 官号长图实测（2026-08-24）

样本：`research/reference/official-longform/2025-12-09-dijiang-update-02.png`，画布 1000 × 2800。
以下为像素扫描所得，非目测估计。这是 β0.3 起的主证据源。

### 排版比例

| 项 | 实测 | 换算 |
| --- | --- | --- |
| 章节标题字高 | 46px | 标题／正文 = **1.77×** |
| 正文字高 | 26px | — |
| 正文基线距 | 42px | line-height ≈ **1.6** |
| 上层条高 ： 标题行高 | 35 ： 66 | 0.53 |
| 左侧黄轨宽 | 20px | 画布 2.0% |

层级靠**字号**撑，不靠字重 —— 这是 β0.3 之前最大的偏差（标题与正文同为 15px，
只有字重差别，于是整体读成扁平 UI 而不是档案页）。

### 章节头构造（两行）

```
上层：[炭灰块 黄色两位编号][灰条 白字 ARKNIGHTS: ENDFIELD]   宽度贴合内容，不铺满
下层：[白纸底 大号黑体标题][黄条 从标题右侧起填满剩余宽度]
```

标题压在**白纸底**上，不是压在黄条上；黄条只占标题右侧的剩余宽度。

### 页眉套准色条

行 y=17–21，高 5px。洋红 `#d025ce` 占 x 61–186，淡黄 `#fcf56d` 占 190–292，
青绿 `#34e3ad` 占 295–605。三段不等宽，起于画布 6.1%、止于 60.5%，右侧留空。
是印刷套准标记，不是装饰满铺。淡黄 `#fcf56d` 是套准色，与主强调 `#ffff0f` 不可混用。

### 其他签名记号

- 图注固定形如 `▌// 行迹高塔`：黄竖条 + 双斜杠 + 标签。
- 专有名词用 `「」` 角括号（`新增「行迹高塔」`），`[ ]` 方括号留给章节标题本身。
- 章节之间是中灰 + 斜纹横带，不是深灰实块。

## 明确排除

- `login_deco_glitch01` 等登录资源证明了全局故障/工业语言，但不是武陵主体证据。
- `deco_guide_xirang_11` 的不规则亮绿故障块更像单次活动插画，不进入核心组件规范。
- 四号谷底的冷硬工业感暂不混入 `alpha.1`，后续如需要应作为独立变体处理。
- 角色战斗演示、战斗特效与场景色不进入 UI 事实表。
