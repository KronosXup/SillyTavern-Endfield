## 可以据此确定

1. 武陵 UI 不能归纳成暗青主题；`deco_guide_wuling_titlebg` 只是一个局部装饰容器证据。
2. 颜色优先编码状态：黄＝主要操作／激活／运行，蓝＝蓝图／液体／预览，红＝错误。
3. 武陵主题辨识度应来自息壤液体系统、自动接续、连通与柔性管线的结构转译，
   而不是给全部 SillyTavern 面板套同一种地区色。
4. 白／黑灰工业骨架属于终末地通用界面语言；浅薄荷绿只能克制地进入地区层。

## 明确不采用

- 视频中的草地、湖水和角色服装颜色不能直接当成 UI 色板。
- 蓝图放置时的全屏蓝色覆盖不能变成聊天常态背景。
- 角色战斗片段及战斗特效不属于本项目 UI 证据。
