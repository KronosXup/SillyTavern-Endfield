## 运行时几何

普通 SillyTavern 1.18.0，`http://127.0.0.1:8000/`，非 modern-ui、非 Luker。
实际应用主题 `Endfield · 档案长图 β0.3` 后读取计算样式，并截图检查。

| 视口 | 面板宽度 | 原生列宽/结构 | 横向溢出 | 字段/标题越界 |
| --- | --- | --- | --- | --- |
| 390×844 | 390px | 364.70px，纵向排列 | 0 | 无 |
| 614×695 | 614px | 588.70px，纵向排列 | 0 | 无 |
| 1184×800 | 592px（50%） | 280.05px + 280.05px | 0 | 无 |

- 三档面板宽度和列宽与修改前一致。
- 收起的**稳定终态**两个内容区高度均为0、原生display为none；即时取样可能落在slideToggle中途，未将中间高度误记为残留。
- 桌面窄列下较长说明自然换为两行，未截断文字或挤出控件。
- 鼠标展开/收起及键盘 Enter 展开实测通过。
- 箭头键盘焦点时一级入口有深灰细轮廓；文本字段焦点保留深灰轮廓和黄短标。
- `#assets_filters`、分类器的LLM/策略组和`#open_chat_expressions`仍保持原生隐藏状态。
- 没有切换分类器、功能开关、当前聊天，也没有点击下载、连接、安装或增删数据。

## 安全审查

- 字段白名单包含无type的资源网址输入，不包含checkbox/radio/file。
- 不给条件显隐容器设置display，不重排`.title_restorable`的恢复按钮。
- 只复位指定说明small的透明度，未覆盖原生复选项依赖灰态或图库的成功/缺失状态。
- 上下内距没有!important，允许原生折叠动画控制临时padding。
- JSON除`custom_css`外字段差异为0；`npm run check`与`git diff --check`通过。
- 部署与构建文件SHA256：`9CE726289C0DA819619554302C91C2A01E89A07EE1BC614883848B77F2ED1910`。
