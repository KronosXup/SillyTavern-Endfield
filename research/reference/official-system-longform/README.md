## 三期共同出现的结构

1. 顶部主视觉、白色信息正文、深灰页脚构成三段，不靠投影分层。
2. 正文白底叠极淡正交小网格和十字定位点；网格不是高对比背景图案。
3. 灰色信息块为均匀平面，用 1px 边界、留白和明度差区分层级。
4. 斜向排线集中在卡片底缘、章节收束和深灰页脚，不铺满正文或外壳。
5. 标题条由功能图标、黄色短底和黑色粗字组成；黄色面积受控，不承担整页底色。
6. 小方块、角标、边缘短刻度和细分隔线反复出现，用于对齐与分组。
7. 每期红／青绿／黄绿版本色主要停留在顶部标签、边缘色带和少量状态点；不属于稳定底色。
