## 跨类别稳定出现的视觉语法

1. **底层是白／浅灰信息平面。** 小网格、定位十字、细刻度和页边编号只在低对比度下辅助对齐，不是铺满页面的主图案。
2. **层级主要靠平面切分。** 黑色分段、灰阶差、1px 细线、留白和局部压边承担分层，投影很弱或没有。
3. **标题和正文反差很大。** 标题使用明显经过选择的展示字形、紧凑字距和大字号；正文保持规整、克制，不能用一套默认无衬线字从头排到尾。
4. **黄色是功能标记。** 黄底短签、状态点和选中态面积受控；红、紫、青绿等大面积颜色通常随版本或内容变化，不能当作长期底色。
5. **工业细节集中在边缘。** 条码、小方块、英文编号、短刻度、局部斜线和色谱线用于收边或分组，不在每张卡片里重复堆叠。
6. **密与疏交替。** 大留白、巨型标题、密集卡片组和实机画面按章节交替出现，长图不会从头到尾保持同一密度。

## 各类别的适用范围

### 协议通行证：干净工程说明纸

- 适合决定聊天正文的白灰底、细网格、标题条和小型状态标记。
- 不复制武器箱、稀有度箭头、巨大数字和武器属性语义。

### 版本内容说明：产品手册／目录

- 适合决定长列表、设置项、章节编号以及白卡嵌套在深色分段中的方式。
- 顶部角色主视觉和红黑版本色只属于当期内容，不决定主题外壳。

### 功能前瞻：功能模块与界面说明

- 适合决定抽屉标题、功能组切换、选中态、信息标签和截图式内容框的层级。
- 实机截图只用来判断信息框与文字的关系，不直接作为酒馆背景或装饰图。

### 档案记录：层叠纸卡与批注

- 适合侧栏、角色抽屉、资料卡的页签、夹层、纸夹、手写线和边缘编号。
- 雪地紫蓝色、破纸纹理和剪贴簿脏污属于这一期档案皮肤，不能铺进聊天正文或整页外壳。
