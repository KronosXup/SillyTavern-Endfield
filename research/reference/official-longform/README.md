## 稳定视觉语法

- 主体不是深色科幻面板，而是白色至极浅灰的连续档案纸面。
- 左侧始终保留窄荧光黄识别条；黄色同时承担章节横条、关键词标记和交互指示。
- 章节用两位数字、细小英文标签和大号黑体中文标题组成，标题常带方括号。
- 白纸底层是约 `10px` 周期的极淡小网格和约 `160px` 周期的交点定位十字；斜线排线只在灰色过渡带、图片说明条和局部暗块增强，彩色细线只作为页眉与页脚校准标记。
- 实机截图嵌入正文证据流，常配黑灰说明条、短引线、图标和小字号注释，而不是独立圆角卡片。
- 深灰区用于章节收尾或危险／升级内容，不应把整套界面做成通篇暗色。
- 一张长图保持连续纵向阅读节奏：封面图 → 信息说明 → 编号章节 → 截图与文字交替 → 深色收束 → `[END]`。

## 对主题设计的直接约束

后续概念应先复刻这种“档案页阅读区”，再映射到 SillyTavern：白灰连续内容面、左侧黄色状态轨、明确的编号分节、局部深灰媒体块。此前官网文章白底只可提供正文排版信息，不能替代本目录的视觉证据。
