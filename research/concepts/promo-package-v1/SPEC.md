# 前瞻文字包装重建标本 v1

> **状态：废弃。** 这是视频后期节目包装重建，不是游戏内 UI，不能作为终末地主题的设计母版。文件仅保留为失败路线记录，不进入 SillyTavern 映射。

## 边界

这不是聊天页面，也不是对剧情对话框的改造。它只重建 2026-08-21 官方「雪凇幽梦」版本前瞻中反复使用的节目包装：章节标题、功能分类标题、要点板和进入顺序。

## 重建规则

逐帧采样只支持近似节奏，不据此虚构精确 easing。标本把功能说明层控制在约 1.25 秒完成，章节标题层控制在约 1.2 秒完成，并提供“重播动效”按钮便于对照。

### 功能说明层

1. 左下锚定，不铺满屏幕。
2. 白色宋体标题带深蓝／紫色错位影。
3. 标题左侧为青色结饰线纹，右侧以白色菱形接出细线。
4. 要点板为蓝紫局部渐变，并叠加稀疏等高线纹。
5. 顺序约为：结饰出现 → 标题左到右揭示 → 菱形与接线延长 → 渐变板擦入 → 两行要点分段揭示。

### 章节标题层

1. 标题置于画面中心附近，仍让背景场景可见。
2. 白色宋体标题使用明显深蓝错位影。
3. 标题背后是左右对称的青色等高线纹与洋红弧形纹；顶部有白色植物形符号。
4. 下缘青色线与小型符号最后补入。

## 本版未做

- 没有映射到 SillyTavern 组件。
- 没有修改或部署 `custom_css`。
- 没有把底下出现过的任务、养成、工业等功能页混成一张界面。
- 没有使用剧情字幕、人物台词或对话框作为样式来源。
