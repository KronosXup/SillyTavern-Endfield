设计取舍与原生边界

A · 默认推荐

表单按原生信息顺序展开。长地址、模型 ID 和状态文字获得整列宽度；动作按钮保持自然宽度。

B · 宽屏备选

内容宽度至少 720px 时，左标签与右侧值形成核对表。低于此宽度恢复单列，深浅层级仍保留。两版均不使用地形、点阵或大编号。

短高度

只有一个面板滚动区，标题与操作不固定占位。430 / 300px 是高度样本，不代表真实手机键盘已经通过。

控件与状态

Custom 保留模型 ID 输入、datalist 与独立可用模型 select。OpenAI 使用原生 select；Ollama 可比较原生选择与宿主已有 Select2。桌面缩窄窗口不会自动变成手机选择器。

连接、取消和测试消息相互独立。真实宿主的测试消息会发出请求并可能计费，本页只模拟结果。真实宿主会把“待测试、跳过检查、地址无效”等非 no_connection 文本也标记为 success；本页保留状态全文，不把小点解释成已验证可用。

实装范围

这里整理了用于比较的字段包裹层，并共用一条模拟状态行；宿主各 API 分支有自己的状态节点。配置操作、完整情境切换与示例提示由本地脚本驱动，不是仅靠 CSS 新增的宿主能力。凭据内容不保存，刷新或恢复即清除。

示例地址使用 example.invalid；所有模型和配置都是虚构数据。只提供本地样本，不读取实际设置、账户或密钥。
