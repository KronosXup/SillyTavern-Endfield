查看结构映射与验收边界

可落为纯 CSS 的部分

两种方向共用项目和 DOM 顺序。颜色、材质、行距、长标签换行、选择与焦点样式可映射到原生 #options .options-content a、#extensionsMenu 与现有 Select2 节点。灰短条由行级伪元素绘制，保留原 FA 图标。

聊天菜单中「删除消息」有明确原生 ID 可单独处理；这不意味着所有弹窗都能由 CSS 判断危险类型。

只属于当前预览的行为

Escape 关闭、子级返回按钮、本地搜索数据与结果回执由本页样例实现，不代表酒馆会新增这些功能。实际聊天菜单由 Popper 定位；扩展挂载方式和专有交互仍由扩展决定。

第三方扩展仅保留一个有明确标识的占位入口，不代表已安装或已通过兼容性测试。此页没有账号、网络请求、生成和删除操作。

建议操作：打开扩展菜单 → 图像生成 → 返回；勾选长中文标签与压缩高度 → 滚动到最后；在下拉列表查看无结果 → 清空 → 选择资料；最后切换 A／B 比较。手机软键盘与真实宿主仍需另验。
