有意简化的范围

本页只展示一张角色卡的主要字段，以及一部世界书的三条虚构条目。未覆盖头像上传、标签管理、备用问候、全部高级字段、书级导入导出、跨书移动、排序与批量改写。字符数是样例计数，不是模型 token 统计。

关键词只演示明文分支；不增加 Select2，也不显示核心已隐藏的 Selective / Use Probability / Add Memo。删除确认只处理本页样例。320 / 390 与短面板用于布局检查，不能代表真机键盘验收。

试用：输入多段文字 → 放大编辑 → Escape 关闭 → 再次打开检查内容。世界书可同时展开多条；关闭和停用均不删除文字。
