设计说明与可实装边界

布局与状态

A 将图标、标题与动作分布在较宽的纸面上；B 以小型炭灰标题栏收束信息。两者保留全部七个场景。

C 只用于一句短问题和从属后果说明，沿用游戏确认框的通栏白带与跨下沿胶囊按钮关系。对象名已经在问题里，不再重复列对象卡片。视口高度不超过 280px 时，问题与说明共同滚动，按钮收回白带内；638×450 预览仍保留跨沿。删除默认聚焦取消。

宿主与验证边界

C 不作为全局弹窗外壳。真实宿主只可将它限定到能够明确识别的简单确认调用；输入表单、选项、长说明与其他通知继续使用各自合适的窗口。不能靠主题 CSS 从按钮文案猜测全部调用类型。

危险样例通过明确的 .scenario-danger 标记呈现。C 保持黄色行动按钮，通过明确的删除问题、红色后果说明与默认取消表达风险。独立页面不读写真实聊天，也不代替宿主或真机验收。

试用顺序：打开场景 → Tab / Shift+Tab → 确认或 Escape → 检查焦点返回。短高度选项用于布局压力检查，不模拟真实手机键盘。
