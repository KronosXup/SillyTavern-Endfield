设计差异、原生映射与边界

A · 页边短签

桌面保持左工具、正文、右动作；短黄签沿纸页上缘伸展。改动最少。窄屏转为文字整行与下方操作行，保证多个真实动作同时存在时仍能写字。

B · 双层书写台

桌面也把全文本纸面与下层工具分开；适合长输入。靠细分隔建立两层，聚焦标记保留在稳定的纸面边缘，输入增高不会改变按钮位置。

C · 边注操作尺

桌面左侧双工具形成纸边操作尺，右侧保留真正的主动作；工具靠浅灰底与细分隔辨认。手机撤回底部工具行，避免挤成窄文本柱。

原生结构优先

主要节点对应 #send_form、#nonQRFormItems、#leftSendForm、#rightSendForm 与 #send_textarea。生成态模拟宿主 body[data-generating="true"]；脚本态使用 .isExecutingCommandsFromChatInput / .script_paused。

此页 JavaScript 只负责交互演示；候选布局和聚焦动作依附原节点即可用 CSS 完成。不会发送真实请求、选择或上传本地文件，也不会保存你的草稿。

附件展示“文件名/数量＋总大小”，移除时清空整批，符合当前原生结构。窄屏预览只验证设计空间，真实手机键盘避让仍需授权实装后单独验收。
