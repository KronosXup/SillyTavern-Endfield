# 实际游戏 UI 样本 01：会客室／赠予自有线索

## 来源与边界

- 来源：官方「雪凇幽梦」版本前瞻，系统优化片段相对时间约 `49.2–51.6s`。
- 稳定帧：`reference/actual-ui/daily-task/clue-list-stable.png`
- 进入过程：`reference/actual-ui/daily-task/clue-list-enter-10fps.png`
- 只分析游戏内“赠予自有线索”菜单。
- 排除 Bilibili 水印、视频字幕和节目左下宣传说明条。
- 排除进入前的线索地图、进入后的奖励确认与干员送礼界面。

## 可直接观察的结构

1. 左侧约占画面三成，是连续纵向列表，不是独立圆角卡片墙。
2. 每行由巨大序号、窄图像、主标题、库存状态和右侧数量组成。
3. 选中行只在局部使用高纯度黄色：序号底、外描边与小型状态线；正文区域仍保持深灰。
4. 未选中行依靠灰阶、图片色和细分隔线区分，没有统一白底卡片。
5. 顶部先给出路径／说明与货币数据；好友筛选、搜索和好友条位于右侧顶部。
6. 右侧主体保持模糊的原页面内容，菜单没有再套一层居中大面板。
7. 主操作固定在左栏底部，用黄色短条确认；黄色不平均分散到所有控件。

## 进入过程

10 fps 采样可确认：

1. 原线索页面先整体虚化、变暗。
2. 左侧栏框架、选中项和底部主操作先出现。
3. 其余列表行与右上好友条在随后约 `0.1–0.2s` 内补齐。
4. 没有观察到大版本章节标题、青色花纹或蓝紫说明板进入游戏 UI。
